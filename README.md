# RepoGit

Настольная библиотека публичных GitHub-репозиториев. Разработчик — PATRIOTIK.

## Запуск и сборка

Необходимы Node.js 20+ и npm. Установите зависимости командой `npm ci`, затем запустите приложение через `npm start`. Сборка Windows (установщик и переносимый EXE): `npm run build:win`. Сборка RPM: `npm run build:linux`; для этого необходимы инструменты RPM.

## GitHub

Вход осуществляется с личным токеном доступа. Для создания собственных репозиториев и загрузки релизов требуется соответствующее право GitHub. Токен хранится в защищённом хранилище операционной системы, если оно доступно; иначе — только в памяти. Проверьте выбранные файлы на наличие секретов до публикации. Приложение создаёт новый репозиторий, не перезаписывая существующий. При неудачной загрузке релиза на GitHub может остаться черновик.

Проверка обновлений использует публичный репозиторий `RUZIK558/RepoGit`. Обновление скачивается отдельно; скачанный установщик или portable-версию нужно запустить вручную. Наличие файла в GitHub не гарантирует его безопасность.

## Автоматическая публикация следующих версий

В исходниках есть GitHub Actions workflow `.github/workflows/release.yml`. После размещения исходников в своём репозитории и разрешения GitHub Actions обновите `version` в `package.json` и `package-lock.json`, затем создайте и отправьте совпадающий тег вида `v0.4.0`. Workflow соберёт установщик, portable EXE и RPM и создаст GitHub Release со всеми файлами. Для работы требуется разрешение Actions на запись в содержимое репозитория; сборки не подписываются. Первый релиз и репозиторий сами по себе этим архивом не создаются.

Если публикуете эту папку через RepoGit с classic token, для файла `.github/workflows/release.yml` GitHub дополнительно требует scope `workflow` (помимо `repo`). Удалите этот файл из выбранной папки, если не хотите давать токену право менять workflows.

## Возможности версии 0.5

Избранные репозитории, поиск по загруженным файлам, открытие расположения файла, проверка последнего стабильного релиза, сравнение SHA-256 с контрольной суммой GitHub при её наличии. Контрольная сумма GitHub не подтверждает безопасность программы или личность автора.
